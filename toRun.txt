# SOCCER ANALYTICS — COMPUTER VISION
## Local Project Operating Guide

### 1. Project Location

`D:\Projects\SOCCER ANALTICAL SYSTEM`

This project contains two independent implementations:

- V1 — Original Soccer Analytics application.
- V2 — Extended football analytics pipeline and dashboard.

Each version has its own Python virtual environment.

### 2. V1 — Original Application

**Environment:** `.venv`

**Launch dashboard:**

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

**Run CLI help:**

```powershell
.\.venv\Scripts\python.exe run.py --help
```

**CLI options:**
- `--video`: Input video.
- `--model`: Model path.
- `--passes`: Enable pass detection.
- `--possession`: Enable possession counter.

The V1 dashboard supports video upload, model selection, team configuration, processing and downloadable annotated video.

### 3. V2 — Extended Analytics Application

**Environment:** `.venv-v2`

**Launch dashboard:**

```powershell
.\.venv-v2\Scripts\python.exe -m streamlit run streamlit_app.py
```

**Run CLI help:**

```powershell
.\.venv-v2\Scripts\python.exe analyze.py --help
```

**Example CLI analysis:**

```powershell
.\.venv-v2\Scripts\python.exe analyze.py --video videos/0bfacc_0.mp4
```

V2 supports:
- Player detection.
- Ball detection.
- Player tracking.
- Team classification.
- Possession analysis.
- Pass and turnover detection.
- Annotated video generation.
- CSV and JSON analytics exports.
- Configurable processing presets and inference settings.

### 7. Testing

Run V2 unit tests:

```powershell
.\.venv-v2\Scripts\python.exe -m pytest tests/ -v
```

Compile project Python files:

```powershell
.\.venv-v2\Scripts\python.exe -m compileall -q .
```

### 9. Environment Separation

Never combine `.venv` and `.venv-v2`.

V1 and V2 intentionally use different NumPy and OpenCV versions. Install dependencies into the appropriate environment.
